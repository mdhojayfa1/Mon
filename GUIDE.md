# 🚀 Automated AI Money-Making Workflow

This repository is designed to generate passive income for you by leveraging AI and Blockchain technology. It automatically writes high-quality content about trending crypto/tech topics and posts them to the **Hive Blockchain**, where you earn rewards (cryptocurrency) based on community engagement.

## 🌟 Why this works
- **Full Free:** Uses the Google Gemini free tier and the Hive blockchain (no-fee posting).
- **Safe:** Complies with GitHub Terms of Service (no resource abuse).
- **Automatic:** Once set up, it posts daily without any manual intervention.

---

## 🛠️ Setup Instructions

To start the automation, you need to add three secrets to your GitHub repository.

### 1. Google Gemini AI (The Writer)
This is the "brain" that writes your posts.
- **Get API Key:** Go to [Google AI Studio](https://aistudio.google.com/app/apikey) and create a **free** API key.
- **GitHub Secret Name:** `GEMINI_API_KEY`

### 2. Hive Blockchain (The Payout Platform)
This is where your content is published and where you get paid.
- **Sign Up:** Create a free account via [InLeo](https://inleo.io/signup) (uses Google/Email) or [Ecency](https://ecency.com/signup).
- **Get Posting Key:** In your Hive wallet, find your **"Private Posting Key"**.
    - *Note:* Hive has multiple keys. You ONLY need the **Posting Key** for this script.
- **GitHub Secret Names:**
    - `HIVE_USERNAME`: Your Hive username (e.g., `monetizer123`).
    - `HIVE_POSTING_KEY`: Your Private Posting Key (starts with '5').

---

## ⚙️ How to Add Secrets
1. Navigate to your repository on GitHub.
2. Go to **Settings** > **Secrets and variables** > **Actions**.
3. Click **New repository secret**.
4. Add the three secrets mentioned above.

## 📊 Monitoring
- **Actions Tab:** Watch the `AI Reward Poster` workflow run daily.
- **Earnings:** Check your Hive account (e.g., on [PeakD](https://peakd.com) or [Ecency](https://ecency.com)) to see your rewards growing.
