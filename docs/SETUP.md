## 🛠️ Step-by-Step Activation

### Step 1: AI Engine (Google Gemini)
1. Get a **Free API Key** from [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Add it to GitHub Secrets as: `GEMINI_API_KEY`.

### Step 2: Blockchain Payouts (Dual Stream)
To maximize earnings, we post to TWO blockchains.

**A. Hive Blockchain (High Engagement)**
1. Sign up at [InLeo.io](https://inleo.io/signup).
2. Get your **Private Posting Key**.
3. Add secrets: `HIVE_USERNAME` and `HIVE_POSTING_KEY`.

**B. Steemit Blockchain (Alternative Stream)**
1. Sign up at [Steemit.com](https://steemit.com).
2. Get your **Private Posting Key**.
3. Add secrets: `STEEM_USERNAME` and `STEEM_POSTING_KEY`.
*(Optional: You can start with just Hive and add Steemit later)*

### Step 3: Affiliate Link System (Optional but Recommended)
1. Open `config/settings.json` in this repo.
2. Edit the `"referral_links"` section with your own affiliate links.
3. The AI will automatically start promoting your links in the daily posts!

## 🛠️ Troubleshooting
If you see a ❌ on your GitHub Actions tab:
1. Click the failed run.
2. Read the **"Multi-Blockchain Broadcast"** logs.
3. It will clearly state if a secret is missing or if a key is invalid.
